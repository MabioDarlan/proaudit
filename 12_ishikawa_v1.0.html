🤖 Ponte com IA — a análise é gerada fora e revisada aqui O que é: rota para produzir a análise com qualquer IA sem que a ferramenta dependa de internet. O prompt já exige a resposta no formato JSON desta ferramenta.

Regra: a IA propõe, o analista decide. Revise, edite, reclassifique e exclua causas antes de usar o diagrama como papel de trabalho.

Exemplo: "Aumento de 40% nos incidentes de acesso indevido ao ERP no 1º semestre de 2026, concentrados em contas de terceiros; auditoria anterior apontou revisão de acessos irregular."

🖱️ Como usar Adicionar: campo na base de cada categoria (Enter funciona); subcausas no campo dentro de cada card.

Editar: duplo clique em qualquer texto — título, efeito, causa e detalhe. Causa vazia mantém o texto anterior; detalhe vazio remove o detalhe.

Reordenar: ▲▼. A ordem no editor é a ordem de leitura, de cima para baixo, no diagrama.

Reclassificar: arraste uma causa para outra categoria (vira principal) ou para outro card (vira subcausa dele). Limite de 3 níveis, imposto pela estrutura.

Excluir: 🗑 (com subcausas, pede confirmação na própria página).

IA: descreva o problema → gere o prompt → rode em qualquer IA → cole o JSON.

Diagrama: projeção automática, somente leitura. "Tamanho real" dá leitura com rolagem; "Exportar SVG" gera o artefato para relatório no tema escolhido. 🎨 Cores Um significado = uma cor, em toda a ferramenta:

Ciano: estrutura do diagrama e causa principal.
Branco / cinza-claro: causa secundária e terciária.
Cinza itálico: detalhe/descrição.
Âmbar: aviso (itens a associar, armazenamento).
Vermelho: erro e exclusão. 📐 Níveis O que é: principal (P) → secundária (S) → terciária (T). Cada nível responde "por que a causa acima ocorre?" (lógica dos 5 Porquês, limitada a 3 níveis).

Regra: o limite de 3 níveis é imposto pela estrutura. As demais regras metodológicas são orientação, não bloqueio.

Exemplo: P "Revisão de acessos irregular" → S "Sem responsável formal pelo processo" → T "Normativo interno não atribui a revisão a nenhuma área".
